# CRM complaints skills (Superbet Greece #ce-crm-gr)

Two Claude Code skills for CRM OPS complaint tickets:

- `ce-crm-gr-queue-sweep/`: one full sweep of the #ce-crm-gr queue (find open tickets, run triage on each, post replies).
- `ce-crm-gr-ticket-triage/`: investigate and answer a single complaint ticket (Betler lookups, campaign resolution, policies and tagging, known bugs).

Install: copy both folders into `~/.claude/skills/`.
